# Changelog

`sentry-testkit` keeps a single, complete changelog covering every release. It is generated automatically by [release-please](https://github.com/googleapis/release-please) from [Conventional Commits](https://www.conventionalcommits.org/), so there is nothing to maintain by hand.

Read the full changelog on GitHub:

**[sentry-testkit CHANGELOG](https://github.com/zivl/sentry-testkit/blob/master/packages/sentry-testkit/CHANGELOG.md)**

Each entry links back to the commits and pull requests it came from, grouped by type — Features, Bug Fixes, Documentation, and more.
